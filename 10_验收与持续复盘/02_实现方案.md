## B. 六结果追溯契约 ★

### B.2 追溯覆盖率契约（复用 Ch1 §E，可单测）

```python
# scripts/trace/traceback_coverage.py —— 六结果追溯覆盖率（复用 Ch1 §E，不另立）
from ch1.trace import traceback            # Ch1 §E 既有实现，本章只调用

SIX_RESULTS = ["change", "company_impact", "transmission",
               "price_reflection", "recommendation", "verification"]   # ①..⑥

def six_results_complete(event_study_id) -> bool:
    """六结果齐备（N10.1-01）：每一环都有 six_results_ref 指向的对象。"""
    refs = load_six_results_ref(event_study_id)
    return all(refs.get(r) for r in SIX_RESULTS)

def traceback_coverage_ok(conclusion_ids: list[str]) -> bool:
    """四要素覆盖率 = 1.0（承 Ch1 §F G1-03）。任一 <1.0 → 未达完成标准。"""
    for cid in conclusion_ids:
        res = traceback(cid)               # 返回 {evidence, assumption, calc, prev_version}
        if min(res.coverage().values()) < 1.0:
            raise TraceIncomplete(cid, missing=res.missing())   # 命中即 fail
    return True
```

### B.3 "原基线 + 新结果"双版本可 diff（N10.1-02）

| 项 | 口径 |
|---|---|
| **`baseline_before`** | 事件研究视图引用**基线旧版本** `version_id`（**不覆盖**，承 Ch9 §3.4.2） |

### B.4 "研究完成"判定器 = 复用 Ch7 §D `gate`（**不新立第二把尺**）

```python
# scripts/verify/research_complete_gate.py —— 完成判定器（复用 Ch7 §D，零新增门槛）
from ch7.decision.gate import research_complete, has_explainable_forecast, DerivedValue

def is_research_complete(company_id, forecast) -> bool:
    """完成判定 = Ch7 §D 门（唯一）。'日报/页面/问答'三信号不参与。"""
    return (research_complete(company_id)
            and has_explainable_forecast(forecast)
            and isinstance(forecast.worksheet, DerivedValue))

def assert_not_fake_complete(signal: dict) -> None:

    assert not (MARKERS & set(RecommendationInput.__dataclass_fields__)), \
        "标记字段出现在决策输入结构（S-07）"
```

- **与既有 checker 的关系**：`error_axis_guard`（S-07）是 **Checker-1 的同族扩展**——**不新增禁词、不放松约束**，只把"标记字段 scope"显式化（对齐 §B.3 的 ★ 禁词作用域通则）；`return_guard`（S-02）**直接复用** Ch9 §3.4.12，无第二实现。
- **为什么必须补这 2 条**：本章"硬冲突 0"**不是"没问题"**——S-07/S-02 是**新层（复盘/错误定位）的守卫缺口**，不补则"标记字段可被偷偷接进决策"或"复盘数字不可比"。
