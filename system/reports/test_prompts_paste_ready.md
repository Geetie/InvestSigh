# 直接复制粘贴版｜3 个窗口

> 判据与观察点见 `test_prompts_boss_daily_usage.md`（那份**不要发给系统**，是给你核对用的）。
> 下面每个代码块都是**纯提示词**，整块复制、一次性发过去即可。编号与那份清单一一对应。

| 窗口 | 内容 | 什么时候开 |
|---|---|---|
| **①** | 只读题 25 条（`S-01`–`S-25`：体检 / 机制 / 研究 / 证据 / 传导） | **现在就能发** |
| **②** | 落库 1 条（`S-26`：把行情与基准写进真源） | 窗口 ① 之后 |
| **③** | 依赖落库的 17 条（`S-27`–`S-43`：价格预期 / 建议 / 事件 / 复盘） | **窗口 ② 确认落库成功后** |

★ 顺序不能反：窗口 ③ 要等 `facts/prices.jsonl` 与 `facts/benchmarks.jsonl` 不再是 0 行。
★ 窗口 ① 若嫌长，可拆成两次发（`S-01`–`S-10` / `S-11`–`S-25`），不影响结论。

## 窗口 ①（现在就能发）

```
接下来我连着问一批问题，请逐条回答。

S-01. 今天怎么没动静？是没变化，还是没跑成功？
S-02. 今天有什么新变化？哪些公司受影响？有没有需要我现在就看一眼的？
S-03. 现在有哪些没做完的、待核验的、失败的？
S-04. 这个结论用的数据是几号的？行情是什么时间的？
S-05. 这个"待判断"是因为缺数据、还是因为真的看不清？
S-06. 现在到哪一步了？能不能进下一个阶段？
S-07. 把那 14 条必测反例跑一遍，逐条告诉我通过还是没通过。
S-08. 全景图上哪些节点只是收录、哪些关系已核验、哪些做完基线、哪些在持续跟踪？
S-09. 那 44 个节点里，还有哪些没做深研？为什么没做？
S-10. 下一批该研究谁？清单怎么定的？
S-11. NVIDIA 现在的研究结论是什么？当前是什么建议、什么期限？跟上一次相比变了什么？
S-12. NVIDIA 靠什么产品和服务赚钱、谁付费？采购或使用怎么变成收入的？主要成本和资本投入是什么？
S-13. 它的增长来自需求扩张、份额、价格、产品组合、单位用量、渗透率还是新业务？每个驱动能持续多久？
S-14. 护城河保护的是份额、定价、成本、客户留存、资本回报还是创新效率？替代方案是什么？失效条件是什么？
S-15. 把这家的完整研究底稿展开：业务与产业位置、增长驱动、增长确定性、护城河、财务与估值、价格与行动。
S-16. 这家公司的判断改过几次？每次是新信息造成的，还是只是措辞变了？
S-17. 这条消息哪来的？原文在哪个页面、哪个段落、视频的哪一分钟？
S-18. 十家媒体都转发了同一条匿名订单消息，那我是不是该信了？
S-19. 就一家券商改了口径，是不是说明市场一致预期变了？
S-20. 官方公告说验证完成了，那是不是等于拿到订单了？
S-21. 这条是第三方调查，官方还没确认，能用吗？
S-22. 上个月引用的那份报告被作者撤回了，之前基于它的结论还算数吗？
S-23. 贴一条消息：这条影响哪些公司？一步一步说清楚是怎么传过去的。
S-24. 云厂商提高资本开支，为什么能推到某家电力公司受益？依据是什么？
S-25. 默认先给我跟这家公司最相关的局部关系（2 跳），需要时再展开到全链（3 跳）。
```

## 窗口 ②（落库动作 · `S-26`）

```
用 MCP 连接器把下面两类数据落进真源（system/facts/），落完逐项告诉我落了什么、来源是哪个连接器、口径是什么。

一、行情 → system/facts/prices.jsonl
- 标的：NVDA（研究标的）与 AGIX（主基准 ETF，代码 usAGIX.OQ）
- 取日线收盘价与行情时间；字段按 PriceSnapshot 必填项：snapshot_id / security_id / price / currency / trading_session
- 复权口径必须显式记录：用 iFinD 取「后复权」收盘价（一次只指定一个口径，并回读 indicators_params 核对它真的按该口径查了）
- 延迟必须标注：tdx 的美股行情带 DelayHQMin: 15，用它取数就标 delayed
- 写入必须走 schema/store.py 的 append_records，不要自己写文件

二、基准 → system/facts/benchmarks.jsonl
- benchmark_id = AGIX（p01 的建议值，未冻结，如实标注"依建议值、未冻结"）
- 从 iFinD 的基金市场补两个 westock 取不到的字段：单位净值、跟踪指数名
- 公司行动（分红 / 拆股）用 tdx 的深度资料取，供 return_basis 的"含分红再投资"口径用

三、落库后重新跑一次每日运行（scripts/daily/run.py --date 今天 --scope full），如实报 blocked 与 gaps 的变化。

最后把两个文件的行数贴出来（wc -l）。
```

★ 这一步结束的标志：**`facts/prices.jsonl` 与 `facts/benchmarks.jsonl` 不再是 0 行**。只在对话里给了张表、真源没变，就不算过。

## 窗口 ③（等窗口 ② 落库成功后）

```
接着问下一批，还是逐条回答。

S-27. 今天这只涨了 X%，为什么？减掉基准的涨跌之后还剩多少？剩下的能归因到哪条消息吗？
S-28. 现在这个价格，需要哪些增长、利润、再投资、风险和持续时间的假设同时成立？给我假设组合和区间。
S-29. 公开预期样本有哪些？样本数多少、来自谁、哪个期间？
S-30. 抛开外部预期，你自己根据业务证据的判断是什么？跟外部预期差在哪、为什么？
S-31. 这条是盘后发的。算收益的时候要注意什么？
S-32. 它今天暴跌，怎么办？
S-33. 昨天美股收盘后，我关心那几家的价格和公告有什么动作？哪些够得上触发复查？
S-34. 现在有什么值得买的？给我买入理由、期限和假设。没有就说没有。
S-35. 这条建议把该给的都给了吗？
S-36. 哪些事实会推翻这个判断？什么情况下该认错？
S-37. 它还涨着呢，为什么建议卖？
S-38. 这家现在说不清，那是要卖吗？
S-39. 它签了个大订单，影响谁？
S-40. NVIDIA 财报出来了，重跑这家和受影响的上下游。
S-41. 按 8 步顺序跑一遍今天的完整研究链路，如实告诉我今天有没有新买卖信号。没跑完的、降级的、缺数据的，都要单独列出来。
S-42. 三个月前那批建议现在结果如何？跑赢 AGIX 了吗？
S-43. 这次判断错了，是来源错了、机制错了、传导错了、财务预测错了、价格预期错了、基准错了，还是时点错了？
```

★ `S-41` 同时是**每日定时任务**的提示词（执行 `scripts/daily/run.py`，建议锚在美股收盘后，北京时间 06:00）。
