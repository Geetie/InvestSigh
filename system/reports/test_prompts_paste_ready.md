# 直接复制粘贴版｜4 个窗口

> 判据与观察点见 `test_prompts_boss_daily_usage.md`（那份**不要发给系统**，是给你核对用的）。
> 下面每个代码块都是**纯提示词**，整块复制、一次性发过去即可。编号与那份清单一一对应。

| 窗口 | 内容 | 什么时候开 |
|---|---|---|
| **①** | 分项只读题 25 条（`S-01`–`S-25`：体检 / 机制 / 研究 / 证据 / 传导） | **现在就能发** |
| **②** | 落库 1 条（`S-26`：把行情与基准写进真源） | 窗口 ① 之后 |
| **③** | 分项：依赖落库的 17 条（`S-27`–`S-43`） | **窗口 ② 确认落库成功后** |
| **④** | ★ **端到端主线**：以 NVIDIA 贯穿 11 个步骤，一条串起全系统 | **窗口 ② 确认落库成功后** |

★ 顺序不能反：窗口 ③ / ④ 要等 `facts/prices.jsonl` 与 `facts/benchmarks.jsonl` 不再是 0 行。
★ 窗口 ① 若嫌长，可拆成两次发（`S-01`–`S-10` / `S-11`–`S-25`），不影响结论。
★ **两种测法，不必都跑**：想快 ⇒ `② + ④`（一条主线看能不能通）；想细 ⇒ `① + ② + ③`。
  窗口 ④ 是**串联版**（覆盖 ①③ 的多个考点，但走一条主线），窗口 ①③ 是**分项版**（逐条判对错）。

## 窗口 ②（落库动作 · `S-26`）

```
用 MCP 连接器把下面两类数据落进真源（system/facts/），落完逐项告诉我落了什么、来源是哪个连接器、口径是什么。

一、行情 → system/facts/prices.jsonl
- 标的：NVDA（研究标的）与 AGIX（主基准 ETF，代码 usAGIX.OQ）
- 取日线收盘价与行情时间；字段按 PriceSnapshot 必填项：snapshot_id / security_id / price / currency / trading_session
- 复权口径必须显式记录：用 iFinD 取「后复权」收盘价（一次只指定一个口径，并回读 indicators_params 核对它真的按该口径查了）
- 延迟必须标注：tdx 的美股行情带 DelayHQMin: 15，用它取数就标 delayed
- 写入必须走 schema/store.py 的 append_records，不要自己写文件

二、基准 → system/facts/benchmarks.jsonl
- benchmark_id = AGIX（p01 的建议值，未冻结，如实标注"依建议值、未冻结"）
- 从 iFinD 的基金市场补两个 westock 取不到的字段：单位净值、跟踪指数名
- 公司行动（分红 / 拆股）用 tdx 的深度资料取，供 return_basis 的"含分红再投资"口径用

三、落库后重新跑一次每日运行（scripts/daily/run.py --date 今天 --scope full），如实报 blocked 与 gaps 的变化。

最后把两个文件的行数贴出来（wc -l）。
```

★ 这一步结束的标志：**`facts/prices.jsonl` 与 `facts/benchmarks.jsonl` 不再是 0 行**。只在对话里给了张表、真源没变，就不算过。

## 窗口 ④（端到端主线 · 前置：窗口 ② 落库成功）

> 这一条是**一条主线串起全系统**：以 NVIDIA 为唯一标的，从立案一路走到复盘，
> 每一步都要「结论 + 依据链 + 缺口」三件套，并**真的写进研究库**（不只是对话里说）。
> 可整块一次发；若系统跑太久，也可按「第 N 步」分次发（同一窗口内继续）。

```
以 NVIDIA 为主线，端到端跑一遍完整的研究链路，把系统现在能做的全部用上。

先做第 0 步：告诉我这个系统现在能做什么、不能做什么、哪些环节缺前置。不要客套，直接列。

然后按下面顺序一步步做。每一步都要给我三样东西：
  ① 结论
  ② 依据链（每条依据带出处，能定位到页面、段落或表格）
  ③ 缺口（做不了就直说做不了、缺什么，不要用套话填）
每一步的结论要真的写进研究库，不要只在对话里说 —— 我要能追溯。

第 1 步｜立案与研究状态
把 NVIDIA 作为研究对象立进研究库；已经在库里就告诉我它现在的深度（只收录 / 关系已核验 / 研究基线完成 / 持续跟踪）和已有记录。告诉我这一步产生了什么可追溯记录。

第 2 步｜业务与产业位置
靠什么产品和服务赚钱、谁付费、从采购到收入是怎么走的、主要成本和资本投入是什么；上游是谁、下游是谁、替代方案是谁。

第 3 步｜增长与确定性
增长来自需求扩张、份额、价格、产品组合、单位用量、渗透率还是新业务；每个驱动标明"已发生 / 计划 / 指引 / 预测"、兑现时间、依赖条件（客户预算 / 供应认证 / 产能 / 能源 / 交付 / 商业化 / 竞争）。兑现时间和置信程度分开写。

第 4 步｜护城河
保护的是份额、定价、成本、客户留存、资本回报还是创新效率；靠什么维持、什么条件下失效。强度和趋势分开写。

第 5 步｜财务与估值
用最近的财报把收入和利润的驱动拆开；给出完整研究底稿（业务与产业位置、增长驱动、增长确定性、护城河、财务与估值、价格与行动）。缺材料就记缺口，不要用模板文字凑。

第 6 步｜证据
从最近的公开信息里挑出真正影响判断的几条，每条给出处（原文在哪、哪一段）。如果多条媒体只是转述同一条消息，说明这算几份证据。

第 7 步｜产业链传导
从 NVIDIA 出发给我最相关的 2 跳关系，需要时再展开到全链（3 跳）。每一步说清：影响变量、方向、幅度或范围、成立条件、反向力量、体现时间。哪些节点只是收录、哪些关系已核验，分开标。

第 8 步｜价格与预期
现在的价格需要哪些增长、利润、再投资、风险和持续时间的假设同时成立，给假设组合和区间；公开预期样本有几份、来自谁、哪个期间；抛开外部预期，你自己根据业务证据的判断是什么，跟外部预期差在哪、为什么。

第 9 步｜结论与建议
现在是什么结论、什么建议、什么期限（具体值 + 起算点 + 复查日期）。要买入就给我理由、假设，以及至少 1 条反证和 1 条证伪条件。没有值得买的就说没有 —— 不要为了给建议而给建议。

第 10 步｜每日维护与复盘
按 8 步闭环跑一遍今天的链路，如实说今天有没有变化（没有变化也是一种结果）。如果有更早的建议，告诉我它们现在的结果，跑赢 AGIX 了吗。如果哪一步判断错了，定位错在七方向里的哪一个（来源 / 业务机制 / 关系传导 / 财务预测 / 价格预期 / 基准预测 / 时点）。

最后给我一张总账：这次跑下来，哪些步骤真的产出了可追溯的记录，哪些只是给了文字没有落库，哪些直接做不了、卡在哪。
```
