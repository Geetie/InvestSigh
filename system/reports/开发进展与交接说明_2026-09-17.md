## 一、这个项目在做什么（一句话 + 边界）

**一句话**：为投资机构"快系统"搭一个**可审计、可复现**的 AI 产业链研究 Agent——
从公开信息到产业链传导到股票建议，**每一步都有唯一真源与机器判据**，而不是"跑出一个看起来不错的答案"。

**核心闭环**（`01_产品目标与核心闭环/01_需求拆解.md`）：8 步研究闭环，起点是"一条真实事件"，终点是"一条可追溯的建议"。

**产品判断（为什么值得做）**：外部同题作业的最大空白是"**产出物标准化**"——换个 Agent 重跑会长成完全不同的样子、跨报告不可比
（见 `system/reports/nvda_task_lessons_for_investsigh.md`）。本项目的对抗手段是：
**23 张 JSONL 唯一真源 + `schema/` + `rules/`（0444 锁）+ 23 道门禁 + 五阶段判据**。这是本仓的**核心价值主张**。

**规模（设计侧）**（`00_交付索引.md`）：11 章 · **376 条原子需求** = ✅ 327 / ⚠️ 49（已收口待收尾）/ ❌ 0 硬缺口；
待冻结参数 11 项；估算 153–215.5 人日。

**三条硬纪律（违反会出事）**：

1. **提交一律 `git add system/`** —— 永不 `git add -A` / `git add .`（防止误把设计区改动或未跟踪产物扫进来）。
2. **门禁必须沙箱外跑**：Python 层 FS broker 会把 `copytree` 变成数万次 IPC，`verify.py` / `run_pytest.sh` 已内置
   `CODEBUDDY_SAFE_DELETE_SANDBOX=0` + `CODEBUDDY_BROKERED_FS_HOOK_ENABLED=0`。Bash 工具的沙箱开关**关不掉它**（它在解释器层）。
3. **两个 pytest 会话禁止并发**：`pytest_sessionstart` 会清空同一个 `tests/.work/`，并发必然互删夹具。

★ 其余全部铁律（`V-01`~`V-12`、`P-01`~`P-09`、`R-01`~`R-06`、纪律 1–12）见 **`system/CONVENTIONS.md`**（唯一权威，**先读它**）。
