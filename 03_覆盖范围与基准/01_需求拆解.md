## 2. 深度挖掘专章

> 第三章原文同样浓缩。以下逐项回答"原文没写、但实现绕不过去"的问题。

### 2.1 反凑数机制："不按预设数量凑名单"如何被执行

**这是第三章最容易被实现成"口号"的地方**——因为"凑数"是人的行为，代码只能约束入口。可落地的三件套：

| 机制 | 实现 | 验收 |
|---|---|---|
| ① 无目标数量配置 | 系统内**不存在** `target_company_count` / `expected_list_size` 之类的配置项或常量（denylist 扫描） | 配置扫描无命中 |
| ② 准入门槛而非数量门槛 | 每个候选对象须提供"原始出处 + 纳入理由 + 证据强度"；准入由**关系核验**产出（N3.1-08） | 无出处/无理由 → 拒绝入正式名单 |
| ③ 数量由结果决定 | 名单规模 = 过门槛对象数；核验后**仅 8 家即收录 8 家**，不补凑、也不为凑数放松门槛（N3.1-09/10） | 人为把门槛调低以凑数 → 门槛变更须版本化+留痕，可见 |

**边界情形（需求方逐句追问时最可能问）**：
- **"如果核验后只有 8 家怎么办？"** → 答案：收录 8 家，如实反映；这属于**正常结果而非失败**。系统不得为"名单好看"而收录弱证据对象（违反 N3.1-10），也不得把"8 家"包装成"首批已完成"（与 N3.2-05 同源：未完成要明示）。
- **"重要性高但证据弱"怎么办？** → 不得入选正式名单；可进"研究线索/待核验"队列（承第六章 gap 语义），但**不占用首批正式名单名额**。

### 2.2 研究深度四态 × 全景图 44 节点

**"全景图"与"深研"必须两个维度分开存**（N3.2-03），否则会出现"在图即视为已研究"的虚假覆盖。建议落地：

| 维度 | 字段 | 取值 | 说明 |
|---|---|---|---|
| 覆盖 | `position_listed`（是否在图） | bool | 44 节点为原型覆盖起点（附录一） |
| 深研 | `research_depth` | 位置收录 → 关系已核验 → 研究基线完成 → 持续跟踪（四态） | 承 N9.1-05；**可回退** |
| 扫描频率 | `scan_frequency` | 逐节点不同（核心生态高频，边缘低频） | 承 N3.2-06 的资源优先级 |

**44 节点的三档状态（附录一）**：

| 档 | 含义 | 附录一中的代表 |
|---|---|---|
| 仅位置收录 | 在图、未核验关系 | 多数边缘节点（如部分电力/网络互连节点） |
| 关系已核验 | 关系有原始出处 | NVIDIA 核心生态上下游 |
| 研究基线完成/持续跟踪 | 已出六项深度底稿 | 首版：NVIDIA 深度样例 + 核心产业链 |

**"未研究≠中性≠无机会"的展示中立性（N3.2-05）**：
- 与 T10"待判断"措辞区分：**待判断** = 已研究但不足以定论；**未完成研究** = 尚未研究。二者都不得渲染为"中性评级"或"无投资机会"。
- 需一条**展示层校验**：渲染函数不得对"未完成研究"节点输出中性/无机会类结论文案（denylist 渲染扫描）。

### 2.3 公司与证券分开管理

**核心结构**（承 N9.1-01/03）：

```
公司（company_id，稳定代理键，研究判断对象）
   └── 1..N 证券（security_id + 上市地 + 币种 + 交易时段，可交易对象）
```

**附录一 44 节点的"实体性质"盘点（决定"非美证券待定"影响面）**：

| 类型 | 节点 | 处理 |
|---|---|---|
| 未上市实体（**进产业研究，不出证券建议**） | OpenAI、Anthropic | 建公司+研究基线，无证券对象、无建议（N3.2-08） |
| 纯非美上市（无美股 ADR，若入推荐需额外处理） | **SK hynix**（韩国 KRX，无美股） | 明确"非美上市证券"样本；是否入推荐范围待定（N3.2-10） |
| 非美公司但有美股 ADR/ADS | ASML（荷，Nasdaq/Euronext）、TSM（台，NYSE ADR）、ARM（英，Nasdaq ADS）、NBIS=Nebius（荷，Nasdaq） | 可用美股证券映射；同时保留原上市地信息 |
| 美股 | 其余（NVDA/AMD/AVGO/…/MSFT/AMZN/GOOGL/META 等） | 直接映射 |

> 结论：附录一中**明确"无美股证券"的仅 SK hynix 一家**；其余非美公司均有美股 ADR/ADS 可用。因此"非美证券是否入推荐范围"的实际影响面较小——**但系统必须能存多证券 + 币种 + 交易时段**（N3.2-07/09），否则未来扩展会被卡住。

**"股票建议必须映射到核实过的证券"的守卫**：
- 建议生成前置校验 `security_id` 已核验（含上市地/币种/交易时段）；未核验 → 不出建议，记 gap（承 N9.1-03 / 07 impl）。
- 无持仓也照常出建议（N3.3-05）——建议是**股票层面判断**，不假设用户持仓（与 Ch2 第 58 行一致）。

### 2.4 环境层与本版边界

**"保留轻量环境研究" ≠ "建环境模块"**：五类环境项应**作为输入**注入公司研究与基准研究，而非独立成模块。

| 环境项（N3.3-01） | 进入哪里 | 承载方式（建议） |
|---|---|---|
| 利率与折现要求 | 第五章估值（WACC/折现率假设） | 估值假设输入（`input_source=model_estimate/manual`） |
| 融资条件 | 第四章增长代价（`financing_need`）/ 增长质量 | 驱动/代价字段 |
| AI 投入与需求周期 | 第七章传导（需求信号边）/ 终值需求 | `demand_signal` 边 + 终端需求归因 |
| 能源与交付约束 | 第七章传导（电力那一跳的门槛） | `location/supply_mode/procurement_link` 门槛 |
| 重要政策变化 | 事件与影响（event/impact） | 事件对象 + 影响六要素 |

**边界守卫（N3.3-02）**：系统中**不得**出现黄金/BTC/跨资产配置模块。可自动化：模块清单 denylist（`gold` / `btc` / `cross_asset_allocation` 等模块名被拒）。

**首版边界（N3.3-03/04/05）**：
- 交付止于"研究 + 股票建议"；
- 无组合权重优化 / 无账户管理 / 无交易执行；
- **不以缺少持仓阻止独立个股研究**（无 position 必填项）——这条与 N3.3-04 需一起看：正因为**不做账户/持仓**，所以研究**不能依赖持仓**。

### 2.5 AGIX 五大特殊规则（第三章的核心）

| # | 规则 | 原文 | 落地要点 |
|---|---|---|---|
| ① | **用基金本身收益** | 第 88 行 | 基准收益 = AGIX 的市场价格总回报；**不允许**用其公开股票指数替代整个基金。需计算守卫（禁用替代指数） |
| ② | **非上市资产缺口/敏感性** | 第 88 行 | AGIX 持非上市资产 → 无法独立建模 → 用 `non_listed_assets` 缺口 + `sensitivity` 表达，不硬编点值（承 05 impl E.1） |
| ③ | **同口径总回报** | 第 90 行 | 相同起止时间 + 美元 + 含分红再投资的市场价格总回报；个股与基准同口径（承 N9.1-23） |
| ④ | **费用不重复扣** | 第 90 行 | 基金费用已含在实际回报中 → 相对收益计算**不得二次扣费**；净值收益仅作诊断。需费用口径守卫 |

**基准语义（N3.4-04）必须精确**：AGIX 表达的是"**选股相对继续持有这一 AI 投资选项是否创造价值**"，**不等于**"全体 AI 上市公司纯行业平均"。措辞错位会让 T07（正收益但跑不赢→卖出）的相对判断口径整体走偏。

### 2.6 "非美证券待定"影响分析（附录一核对结论）

- **受影响的节点**：仅 SK hynix（无美股）；OpenAI/Anthropic 本就不出证券建议（不受影响）。
- **若首版推荐范围限定"美股为主"**：SK hynix 只能研究、不能出建议；其余非美公司经美股 ADR/ADS 可正常映射。
- **系统影响**：无论首版是否纳入，系统**必须**支持（证券、上市地、币种、交易时段）多证券建模（N3.2-07/09），并把"推荐范围"做成**可配置参数**（N3.2-10），而非硬编码。
- **待冻结**：非美证券是否入推荐范围（第十一章参数"股票建议范围"）。实现方须在参数冻结前保持可切换。
